# Atividade - Branchs

Projeto desenvolvido para a atividade de controle de versões com branches.

## Funcionalidades

- Login de usuário
- Cadastro de produto
- Listagem de produtos
- Carrinho de compras
- Pagamento via PIX
- Relatório de vendas

## Como executar

1. Clone o repositório.
2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` no navegador (ou execute os scripts conforme cada funcionalidade).
